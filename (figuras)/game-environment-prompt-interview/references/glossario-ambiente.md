# Glossário de ambiente — banco de opções por categoria

Use estas listas como banco de opções ao montar perguntas com
`ask_user_input_v0`, ou como inspiração para sugerir ideias ao usuário em
texto livre. Não é uma lista fechada — o usuário pode sempre propor algo
diferente, e isso deve ser aceito normalmente.

underwater reef, floating sky islands, autumn woodland, bamboo grove
